# Learning-Stuff

A small collection of projects while learning to build things.

## 🕹️ Neon Dodger

A polished, dependency-free browser arcade game built with vanilla HTML, CSS, and JavaScript.

**Play:** open `games/neon-dodger/index.html` in a browser.

### Features
- 🎮 Keyboard controls: **A/D** or **←/→**
- 📱 Touch and drag controls
- ⏸️ Pause with **Esc**
- 🏆 Persistent high score with `localStorage`
- 📈 Difficulty increases as your score climbs
- ✨ Particle effects and responsive arcade UI
- 🚫 No frameworks or dependencies

### Project structure

```
games/
└── neon-dodger/
    ├── index.html
    ├── style.css
    └── game.js
```

## Running locally

No build step is required. Either open the HTML file directly or serve the repository with any static HTTP server.

Have fun experimenting and changing the game!
