# Learning-Stuff

A small collection of projects while learning to build things.

## 🕹️ Neon Dodger

A polished, dependency-free browser arcade game built entirely in **one HTML file**.

**Play locally:** open `games/neon-dodger.html` in a browser.

### Features
- 🎮 Keyboard controls: **A/D** or **←/→**
- 📱 Touch and drag controls
- ⏸️ Pause with **Esc**
- 🏆 Persistent high score with `localStorage`
- 📈 Difficulty increases as your score climbs
- ✨ Particle effects and responsive arcade UI
- 📄 Everything is contained in one HTML file
- 🚫 No frameworks or dependencies

### Project structure

```
games/
└── neon-dodger.html
```

## Running locally

No build step is required. Download the repository and double-click `games/neon-dodger.html` to play.

Have fun experimenting and changing the game!
